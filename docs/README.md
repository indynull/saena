# Sitting book

Saena is a desk. One tree of work, deeds, tickets, and memory.
A sitting ends by naming a deed. Every checkout talks to the
same home desk. A project file is how a folder joins that tree.

Read [VISION.md](../VISION.md) for the law. This book is the
