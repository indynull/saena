# Memory

`Remember:` and `Prefer:` hang an atom on the tree. The host
commits the atom. A tool dump is refused.

```sh
saena memory remember "always open the deed, not the chat"
saena memory prefer "Borda then maximal marginal relevance"
saena memory pin review
saena search "deed"
saena memory cards
```

`pin` scopes remember and search. Human cards are `USER.md` and
`MEMORY.md` beside the home desk. Search merge is the host
panel: `SAENA_FUSE`, `SAENA_DIVERSIFY`, `SAENA_DECAY`. Default
is Borda then maximal marginal relevance.
